# Notes: server

Detailed notes moved out of `CLAUDE.md` (the hard rules stay there). Read this before editing `server.py`.

- `server.py` — Python 3 server (stdlib only apart from the AI SDKs), configured through env vars (`DASHBOARD_HOST` default 127.0.0.1, `DASHBOARD_PORT`, `DASHBOARD_PUBLIC_URL`, `DASHBOARD_TRUST_PROXY`, `DASHBOARD_REGISTRATION`, `DASHBOARD_DB`). Public: `GET /` and `/api/auth/{me,login,login-mfa,register,verify,resend,forgot,reset}`; everything else (`/api/data`, `/api/ask`, `/api/ai-info`, `/api/ai-keys`, `/api/import-statement`, `/api/auth/{logout,change-password,mfa/setup,mfa/enable,mfa/disable}`) goes through `_require_session()`, and POSTs also check the CSRF header. Each request must carry an allowed `Host` (the `DASHBOARD_PUBLIC_URL` netloc, or `localhost:PORT` / `127.0.0.1:PORT` when unset — blocks DNS rebinding); every POST must be `Content-Type: application/json` and any `Origin` must be an allowed host; bodies are size-capped per endpoint (`_read_json(max_bytes)`). Session cookie: `HttpOnly; SameSite=Strict`, plus `Secure` and the `__Host-` prefix when the public URL is https; security headers are added in `end_headers()`. CSP: JSON responses get `default-src 'none'`; the HTML page gets a per-response nonce injected into every `<script` tag by `_send_file()` (so an injected `<script>` does not run; Chart.js from jsdelivr keeps its SRI) — **any new `<script>` must be a literal `<script` in the HTML file so it receives the nonce**. `script-src-attr 'unsafe-inline'` and `style-src 'unsafe-inline'` remain on purpose because the page has ~110 inline `onclick=`/`onchange=` handlers and inline styles; removing them (event delegation) is what would allow a fully strict CSP. Optimistic concurrency on `/api/data`: GET returns an `ETag`, each POST sends it as `If-Match`; 409 if it changed (another tab), 428 if missing. Everything is `Cache-Control: no-store` on purpose. There is **no** shutdown endpoint any more (stop with SIGTERM/Ctrl+C; writes are SQLite transactions). `X-Forwarded-For` is trusted only from 127.0.0.1 and only with `DASHBOARD_TRUST_PROXY=1` (last value). The page is re-read from disk on every request but Python modules only at startup, so restart after changing Python code.
