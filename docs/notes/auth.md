# Notes: auth

Detailed notes moved out of `CLAUDE.md` (the hard rules stay there). Read this before editing `auth.py`.

- `auth.py` — SQLite (`app.db`, mode 600, WAL) with tables `users`, `sessions`, `user_data` (the former `dati.json`, plus an integer `version` used as ETag `"v<N>"`), `user_ai_config` (the former `ai-config.json`) and `invites`; email verification and password reset via single-use hashed tokens in `email_tokens` (24 h / 1 h; accounts created while SMTP is configured start `verified=0` and cannot log in until confirmed; a duplicate registration returns the same 202 as a new one and mails the owner instead; forgot/resend answers are always identical and mails are capped per recipient by `_may_mail`; a reset closes every session but does **not** bypass 2FA); TOTP 2FA (RFC 6238, stdlib; `totp_last_step` blocks replay, login with 2FA returns an `mfa_token` valid 5 min / 5 attempts before any session exists, 8 single-use recovery codes stored hashed; disabling needs password + code); `encrypt_secret`/`decrypt_secret` (AES-256-GCM via `cryptography`, `DASHBOARD_MASTER_KEY`, `enc1:` prefix, bound to the row with a context like `ai:<user_id>` / `totp:<user_id>`; `server.py` refuses to start online without the key and migrates plaintext values with `encrypt_existing()`); passwords hashed with stdlib `hashlib.scrypt` (N=2^15, per-user salt, `compare_digest`, dummy hash for unknown emails so timing doesn't reveal accounts, NFKC-normalized, 12–256 chars); sessions store only the SHA-256 of the cookie token plus a CSRF token, idle 12 h / absolute 14 days; in-memory `Throttle` for failed logins (per account and per IP) and per-user limits. **Every data function takes the `user_id` from the session, never from request input** — keep it that way for any new endpoint. Registration mode `DASHBOARD_REGISTRATION` = `invite` (default, single-use codes) | `open` | `closed`. Security events go to stderr through `log_event()`. CLI: `python3 auth.py create-invite | import-legacy EMAIL | reset-password EMAIL | gen-master-key | encrypt-existing`.
