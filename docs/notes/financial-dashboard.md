# Notes: financial-dashboard

Detailed notes moved out of `CLAUDE.md` (the hard rules stay there). Read this before editing `financial-dashboard.html`.

- `financial-dashboard.html` — the whole dashboard (HTML + CSS + JS in one file), served by `server.py`. A first `<script>` ("// ===== Accesso") asks `GET /api/auth/me` synchronously: with no session (or when the URL fragment is `#verify=TOKEN` / `#reset=TOKEN`, from the emails — the token is read and stripped from the URL at once) it builds the auth screens with the `h()` DOM helper (login, 2FA code, register, forgot/reset password, email verification; never `innerHTML` with variable text) and sets `window.__authRequired`, which makes the main script throw at its first line (nothing else runs until the post-login reload). It also wraps `fetch` so every POST carries `X-CSRF-Token` (`window.__csrf`; one retry after a 403 via `window.__refreshSession()`, which refuses to continue if a *different* account logged in from another tab → `'other'`). The top bar has an "⚙️ Impostazioni" dropdown menu (`toggleSettingsMenu()`) holding Importa backup, Importa estratto conto, Esporta dati, Aggiorna dati, 🔑 Chiavi API (`openApiKeysModal()`, a modal wrapping `#apiKeysList`), 🧠 Memoria del consulente (`openMemoryModal()`, modal with the advisor memory note, editor and fixed rules), Sicurezza and the theme toggle; email, sync status and "Esci" stay in the bar. The "🔐 Sicurezza" item (`openSecurityModal()`) changes the password and enables/disables TOTP 2FA (secret + recovery codes shown once). The "⏻ Esci" button (`logoutDashboard()`) saves, then `POST /api/auth/logout`. The AI chat goes through `askAdvisor()` → `/api/ask`; `loadAdvisorInfo()` reads `/api/ai-info`. The `#fileSyncStatus` header indicator shows whether writes are reaching the server.
